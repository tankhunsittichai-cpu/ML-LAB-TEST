# LAB 6 - Neural Network Classification (Age, Gender, and Ethnicity Dataset)

โปรเจกต์นี้เป็นการทดลองพัฒนาระบบ Machine Learning ด้วยอัลกอริทึม Neural Network (โครงข่ายประสาทเทียม) เพื่อจำแนกประเภทข้อมูล (Classification) บนชุดข้อมูลภาพใบหน้า โดยมุ่งเน้นที่การเปรียบเทียบประสิทธิภาพของโมเดลเมื่อมีการปรับเปลี่ยนโครงสร้าง (Configurations) เช่น จำนวนชั้นซ่อน (Hidden Layers), จำนวนเซลล์ประสาท (Neurons) และจำนวนรอบในการฝึกสอน (Epochs)

---

### 1. โครงสร้างโปรเจกต์
ระบบถูกออกแบบให้ทำงานแบบแยกส่วน (Modular) เพื่อความสะดวกในการอ่าน จัดการ และนำไปต่อยอด:

*   `main.py` : ไฟล์หลักที่เรียกใช้งาน Pipeline ทั้งหมด ตั้งแต่การเตรียมข้อมูล การรันโมเดลหลายรูปแบบ ไปจนถึงการประเมินผลและการบันทึกไฟล์
*   `data_loader.py` : โหลดชุดข้อมูลจากไฟล์ CSV
*   `preprocess.py` : ทำความสะอาดข้อมูล แปลงค่าพิกเซล (pixels) เป็นอาร์เรย์ตัวเลข ทำ Label Encoding ให้กับ Target และทำ Standardization
*   `spilt_data.py` : แบ่งข้อมูลออกเป็นชุดสำหรับฝึกสอน (Train) และชุดทดสอบ (Test)
*   `nn_model.py` : สร้างและฝึกสอนโมเดล Neural Network (Multi-Layer Perceptron) ด้วยไลบรารี TensorFlow/Keras
*   `evaluate.py` : ประเมินความแม่นยำ (Accuracy) และสร้างกราฟประวัติการฝึกสอน (Training/Validation Loss & Accuracy)
*   `test_nn.py` : สคริปต์เสริมสำหรับทดสอบการทำนายข้อมูลรายบุคคล
*   `output/` : โฟลเดอร์สำหรับจัดเก็บไฟล์ที่ระบบสร้างขึ้นทั้งหมด (ภาพกราฟ `.png` และไฟล์สรุปผลททดลอง `.txt`)
*   `age_gender(1)_2.csv` : ไฟล์ชุดข้อมูลต้นฉบับ (ต้องนำมาวางไว้ในโฟลเดอร์หลัก)

---

### 2. Dataset ที่ใช้
ไฟล์ข้อมูลที่เลือกใช้คือ `age_gender(1)_2.csv` (ข้อมูลพิกเซลรูปภาพใบหน้าบุคคล):

*   **Target:** คอลัมน์ `ethnicity` (เชื้อชาติ) *(หมายเหตุ: ใช้ทำนายเชื้อชาติแทนเพศ เนื่องจากในชุดข้อมูลย่อยนี้มีคลาสของเพศเพียงคลาสเดียว)*
*   **Features:** คอลัมน์ `pixels` ซึ่งประกอบด้วยค่าความสว่างของพิกเซลในรูปภาพที่ถูกแปลงสภาพเป็นตัวเลข
*   **Preprocessing Need:** ข้อมูลพิกเซลถูกเก็บอยู่ในรูปของข้อความ (String) ที่คั่นด้วยช่องว่าง จึงต้องทำการแยกและแปลงเป็น Numpy Array ก่อนใช้งาน

---

### 3. วัตถุประสงค์ (Objectives)

1. เพื่อประยุกต์ใช้โมเดล Neural Network (NN) ในงาน Classification บนชุดข้อมูลรูปภาพ
2. เพื่อเปรียบเทียบประสิทธิภาพการทำงานของโมเดลเมื่อใช้จำนวน Epochs ที่แตกต่างกัน (เช่น 20 vs 50 Epochs)
3. เพื่อเปรียบเทียบโครงสร้าง Neural Network (Configurations) ที่ต่างกัน เช่น การปรับจำนวน Hidden Layers และจำนวน Neurons (1 ชั้น 32 นิวรอน เทียบกับ 2 ชั้น 64-32 นิวรอน)

---

### 4. กระบวนการทำงาน (Workflow)

1. **Data Loading:** โหลดข้อมูล `age_gender(1)_2.csv`
2. **Preprocessing:** แปลงข้อมูลพิกเซลให้อยู่ในรูปตัวเลข Array และใช้ `LabelEncoder` แปลงกลุ่มเป้าหมาย (Target) ให้เริ่มจาก 0 เพื่อให้เข้ากับโมเดล Neural Network
3. **Data Splitting:** แบ่งชุดข้อมูลออกเป็น Train (70%) และ Test (30%)
4. **Standardization:** ปรับสเกลของ Features ให้มีค่าเฉลี่ยเป็น 0 และส่วนเบี่ยงเบนมาตรฐานเป็น 1 ด้วย `StandardScaler`
5. **Model Training:** สร้างและฝึกสอนโมเดล Neural Network 3 รูปแบบตามโจทย์ (ปรับแต่ง Layers และ Epochs)
6. **Evaluation & Export:** ประเมินความแม่นยำ ทำนายผล สร้างกราฟแสดง Loss/Accuracy ในแต่ละรอบของการ Train และบันทึกผลการเปรียบเทียบทั้งหมดลงในโฟลเดอร์ `output/`

---

### 5. คำอธิบายสั้น ๆ ของเทคนิคที่ใช้

*   **Neural Network (TensorFlow/Keras):** อัลกอริทึมจำลองการทำงานของโครงข่ายประสาทในสมองมนุษย์ ประกอบด้วยชั้นรับข้อมูล (Input Layer), ชั้นซ่อน (Hidden Layers) เพื่อคำนวณความซับซ้อน และชั้นส่งออก (Output Layer)
*   **ReLU Activation Function:** ฟังก์ชันกระตุ้นที่นิยมใช้ในชั้น Hidden Layers เพื่อช่วยให้โครงข่ายสามารถเรียนรู้รูปแบบที่ซับซ้อนได้อย่างรวดเร็วและแก้ปัญหาความชันหายไป
*   **Softmax:** ฟังก์ชันสำหรับชั้น Output ที่ใช้แปลงค่าผลลัพธ์ให้อยู่ในรูปของความน่าจะเป็น (Probability) สำหรับการแยกแยะข้อมูลแบบหลายคลาส (Multi-class Classification)
*   **Adam Optimizer:** อัลกอริทึมช่วยปรับค่าน้ำหนัก (Weights) ของโมเดลให้มีประสิทธิภาพและเข้าถึงจุดที่ Error ต่ำที่สุดได้รวดเร็วขึ้น
